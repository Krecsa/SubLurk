# SubLurk

**SubLurk** - Android-приложение для пассивной разведки доменов (OSINT).

## Дисклеймер

Автор **не несёт ответственности** за то, как будет использоваться приложение. Все данные берутся из **открытых источников** (crt.sh, Google DNS, IPinfo, RDAP). Приложение **не выполняет** активного сканирования, **не нарушает** работу серверов и **не осуществляет** неправомерный доступ к информации.

## Что делает

- Поиск поддоменов через Certificate Transparency Logs (crt.sh)
- DNS-записи через Google Public DNS
- IP + геолокация через IPinfo
- WHOIS-информация через RDAP

Всё это - **из публичных источников**. Приложение **не выполняет** активного сканирования, **не атакует** серверы и **не обходит** защиты.

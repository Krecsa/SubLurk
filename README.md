# SubLurk

**SubLurk** - Android-приложение для пассивной разведки доменов (OSINT).

## Дисклеймер

Автор **не несёт ответственности** за то, как будет использоваться приложение. Все данные берутся из **открытых источников**. Приложение **не выполняет** активного сканирования, **не нарушает** работу серверов и **не осуществляет** неправомерный доступ к информации.

## Что делает

- Поиск поддоменов через Certificate Transparency Logs (crt.sh, Cert Spotter)
- DNS-записи через Google Public DNS
- IP + геолокация через IPinfo
- WHOIS-информация через WHOIS-сервис

Всё это - **из публичных источников**. Приложение **не выполняет** активного сканирования, **не атакует** серверы и **не обходит** защиты.

## Функционал

- **Поиск поддоменов** с автоматической фильтрацией мусора (email, IP-адреса)
- **Fallback-система**: если crt.sh недоступен, запрос идёт в Cert Spotter
- **Офлайн-режим**: результаты кешируются в Room
- **Тёмная и светлая темы** с возможностью выбора
- **Локализация**: English / Русский
- **Фильтр**: скрытие приватных IP-адресов в DNS-записях

## Технологии

- Kotlin, Coroutines, Flow
- Retrofit + OkHttp + Gson
- Dagger Hilt (DI)
- Room (офлайн-кеш)
- DataStore (настройки темы и языка)
- Navigation Component (Single Activity)
- Material Design 3
- GitHub Actions (CI)
- JUnit (Unit-тесты)
